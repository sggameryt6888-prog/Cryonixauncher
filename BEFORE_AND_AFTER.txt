                      WHY IT WAS CRASHING
═══════════════════════════════════════════════════════════════════════════════

The Original Code (BROKEN):
┌─────────────────────────────────────────────────────────────────────────────┐
│ if (!System.getProperty("os.name").toLowerCase().contains("win")) {        │
│     externalNativeBuild {                                                  │
│         ndkBuild {                                                         │
│             path file('src/main/jni/Android.mk')                          │
│         }                                                                  │
│     }                                                                      │
│ }                                                                          │
└─────────────────────────────────────────────────────────────────────────────┘

What this did:
  ❌ On Windows: Skipped NDK build entirely
  ❌ Native libraries never compiled
  ❌ APK missing libexithook.so (and other vital libraries)
  ❌ App crashes on startup with: "library libexithook.so not found"


The Fixed Code (WORKING):
┌─────────────────────────────────────────────────────────────────────────────┐
│ externalNativeBuild {                                                      │
│     ndkBuild {                                                             │
│         path file('src/main/jni/Android.mk')                              │
│     }                                                                      │
│ }                                                                          │
└─────────────────────────────────────────────────────────────────────────────┘

What this does:
  ✅ All platforms: Builds native libraries
  ✅ Windows: NDK now compiles libexithook.so, etc.
  ✅ All libraries included in APK
  ✅ App launches successfully without crashes
