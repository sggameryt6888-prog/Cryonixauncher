⚡ IF BUILD FAILS
═══════════════════════════════════════════════════════════════════════════

Error: NDK not found
  → Open Android Studio
  → Settings → SDK Tools → Check "NDK (Side by side)"
  → Click Apply

Error: Java not found
  → Install JDK 11+: https://www.oracle.com/java/technologies/javase-downloads.html

Error: Out of memory
  → Edit gradle.properties
  → Change: org.gradle.jvmargs=-Xmx6144M

For more help, see: BUILD_INSTRUCTIONS.md
